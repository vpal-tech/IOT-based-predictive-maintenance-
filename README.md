# IoT Based Predictive Maintenance System for Industrial Motors

## Project Overview
This project is an IoT-based predictive maintenance system for industrial motors. It monitors motor data and helps predict possible failures in advance.

## Technologies Used
- Python
- Machine Learning
- IoT
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## Features
- Motor condition monitoring
- Sensor data analysis
- Failure prediction
- Predictive maintenance dashboard
- Data visualization

## Objective
The main objective is to predict motor failures early and reduce unexpected machine downtime.

## Project Type
B.Tech CSE (AI) Minor Project
